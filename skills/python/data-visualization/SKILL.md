# Python Data Visualization

## Purpose

Choose and build clear data visualizations that accurately communicate the intended analysis.

## When to use

Use when exploring data, communicating comparisons, or preparing analytical figures.

## Instructions

1. Start from the analytical question and variable types.
2. Choose a chart that exposes the intended comparison.
3. Label units, axes, uncertainty, and transformations.
4. Avoid misleading scales and unnecessary decoration.
5. Verify that plotted data matches the source data.
6. Make important assumptions visible.

## Inputs

- Dataset or computed results
- Analytical question
- Audience and presentation constraints

## Outputs

- Appropriate visualization plan or figure
- Labels and annotations
- Interpretation of the visualized comparison
- Relevant caveats

## Example

User: "Show how two variables change over time."

Expected behavior: inspect variable types and time structure, then select and label an appropriate visualization without distorting the scale.

## Limitations

A visualization can clarify patterns but cannot establish causation. Poor sampling, aggregation, or scale choices can still mislead.
