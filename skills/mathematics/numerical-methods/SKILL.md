# Numerical Methods

## Purpose

Solve numerical-method problems with explicit convergence, stopping criteria, and error checks.

## When to use

Use when approximating roots, solving numerical systems, interpolating data, or applying numerical algorithms.

## Instructions

1. Identify the mathematical problem, assumptions, inputs, stopping criterion, and expected accuracy.
2. Select an appropriate numerical method.
3. State the recurrence or algorithm.
4. Compute iterations carefully.
5. Report residual or error estimates.
6. Check convergence conditions.
7. Distinguish numerical approximations from exact results.

## Inputs

- Mathematical problem and data
- Numerical method constraints
- Desired tolerance or accuracy

## Outputs

- Selected numerical method
- Iterations or algorithm
- Approximate result
- Error or residual estimate
- Convergence assessment

## Example

User: "Find a root of this equation using Newton-Raphson to a tolerance of 10^-5."

Expected behavior: state the iteration formula, apply it until the stopping criterion is met, and report the approximation and error information.

## Limitations

Numerical methods can fail to converge or become unstable depending on initial values, conditioning, rounding, and method assumptions.
