# Evidence Comparison

## Purpose

Compare evidence from multiple sources without treating disagreement as automatically equivalent evidence.

## When to use

Use when sources address similar claims and their methods, populations, or conclusions need to be compared.

## Instructions

1. Extract the claim, population or system, method, evidence, uncertainty, and limitations from each source.
2. Check whether sources actually answer the same question.
3. Distinguish primary evidence, secondary analysis, and speculation.
4. Conclude what is supported, uncertain, or unresolved.
5. Identify evidence that could resolve important uncertainty.

## Inputs

- Multiple sources
- Claims to compare
- Relevant context or scope

## Outputs

- Evidence comparison
- Agreement and disagreement analysis
- Supported and unsupported claims
- Remaining uncertainty

## Example

User: "Which of these studies provides stronger evidence for the claim?"

Expected behavior: compare study design and direct evidence before making a conclusion.

## Limitations

Evidence strength cannot be judged reliably when key methodological or contextual information is missing.
