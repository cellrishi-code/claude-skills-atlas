# Licensing and Attribution

The Atlas should make the origin and permitted use of contributed resources clear.

## Original contributions

For original work, contributors should state the license under which the resource is released and identify the author or contributor when attribution is required.

## Derived or third-party resources

If a resource is based on, adapted from, or incorporates third-party material:

- Identify the original source.
- Include a source URL when available.
- State the applicable license.
- Provide the attribution required by that license.
- Follow any additional terms or notices required by the original work.
- Do not copy material when its license does not permit the intended use.

## Skill metadata

When a skill contains source, source_url, or derived_from metadata, it should also include license and attribution metadata so provenance is explicit.

## Before opening a pull request

Check that:

1. The resource's license is known.
2. Required attribution is present.
3. Third-party terms are compatible with the contribution.
4. Source links are accurate.
5. No confidential or private material has been included.

When licensing is unclear, ask a maintainer before contributing.
